# preaser-game.html
בעת לחיצת כפתור התחל, מתחילים למדוד זמן, ומציגים שורה של 10 מספרים אקראיים בני 4 ספרות כל אחד.
השחקן צריך ללחוץ על המספרים מהקטן אל הגדול לפי הסדר.

אם תלחץ על מספר נכון, צבע הרקע של המספר יהיה ירוק

אם טעה, יישמע צליל חצי שניה וצבע הרקע יהיה אדום זמן זה.

בטעות השלישית המשחק נגמר בהפסד

יש להציג את המסך את משך המשחק, ואת המשחק הטוב ביותר עד כה (כלומר משך המשחק שהסתיים בהצלחה)
